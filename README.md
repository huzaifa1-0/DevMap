# DevMap

DevMap is a VS Code extension that tracks your JavaScript, Node.js, and Express learning progress in real-time as you code.

## Features

- **AST Parsing on Save**: Every time you save a `.js`, `.ts`, `.jsx`, or `.tsx` file, DevMap parses the code and detects syntax patterns using Babel.
- **Curriculum Tracker Sidebar**: A native tree view in the activity bar showing completed and pending learning concepts.
- **Webview Dashboard**: An interactive, premium dark-themed dashboard presenting your learning progress in Chart.js bar charts and detailed status grids.
- **Interactive Documentation**: Click any topic in the sidebar or dashboard to open its official MDN/Node/Express documentation.
- **Gamified Achievements**: Toast notifications pop up when you unlock new programming topics for the first time.

## Quick Start

1. Open the project workspace in VS Code.
2. Press `F5` to open the **Extension Development Host**.
3. Create/save files in the host window.
4. Open the DevMap icon in the activity bar or run the command `DevMap: Open Web Dashboard` to view your stats.
